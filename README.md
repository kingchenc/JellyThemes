## Quick Install

Go to **Dashboard > Branding > Custom CSS** and paste one of these.
On Jellyfin 10.10 and older, Custom CSS is under **Dashboard > General**.

> [!NOTE]
> The themes work with every display mode of Jellyfin 12: **Auto** (the new interface), **Desktop**, **Mobile** and **TV**. You find it under **User Settings > Display > Display Mode**.

### 🟣 Obsidian (Purple)

```css
@import url("https://cdn.jsdelivr.net/gh/kingchenc/JellyThemes@master/Themes/Obsidian/Obsidian.css");
```

## Features

- Dark design with one accent color per theme, in the new Jellyfin 12 interface, its menus and Live TV, and in the dashboard of Jellyfin 10.10 / 10.11
- Floating glass top bar with blur, glowing cards that grow a little on hover
- Login page as one glass card, with your own logo if you like
- Play button in the middle of cards, floating progress bars, badges in the corner of cards, pill tabs
- Item pages with a fading backdrop, a labelled Play / Resume button in your language and round photos of the cast
- Episodes of a season as tiles
- Your own colors, blur, speed and corners, see [Settings](#settings)
- Small and fast: one file of about 65 KB (12 KB over the network) plus the 3 KB logo, no web fonts, no `:has()`
- Works in the browser, the desktop and mobile apps, on iOS and on TVs (Samsung, LG)
- Everything is on by default; anything can be switched off, see [Settings](#settings)

## Settings

Add a `:root { ... }` block **under** the `@import` line in Custom CSS and set what you want to change. For example:

```css
@import url("https://cdn.jsdelivr.net/gh/kingchenc/JellyThemes@master/Themes/Solaris/Solaris.css");

:root {
    --jt-header-backdrop: none;
    --jt-footer: none;
}
```

| Setting | Default | What it does |
|---------|---------|--------------|
| `--jt-header-backdrop` | `blur(14px) saturate(140%)` | Blur under the top bar and behind the login card. Less blur: `blur(6px)`, none: `none` |
| `--jt-header-gap` | `0.6em` | Space around the floating top bar. `0` makes it full width again |
| `--jt-header-radius` | `1em` | Corner radius of the top bar. Use `0` together with `--jt-header-gap: 0` |
| `--jt-header-width` | `95.5%` | Width of the top bar on desktop and TV, centered. `93.4%` lines it up with the page content, `100%` = full width. Phones always get the full width |
| `--jt-glow` | accent glow | Glow around hovered cards. `none` turns it off |
| `--jt-glow-s` | accent glow | Glow of buttons. `none` turns it off |
| `--jt-motion` | `0.2s` | Speed of hover animations, e.g. `0.4s` for slower. `0s` turns them off |
| `--jt-motion-fast` | `0.15s` | Speed of small animations (letters, play button). `0s` turns them off |
| `--jt-card-radius` | `0.6em` | Corner radius of cards |
| `--jt-radius` | `0.65em` | Corner radius of buttons, fields and panels |
| `--jt-card-zoom` | `1.04` | Size of a hovered card. `1` turns the zoom off |
| `--jt-progress-gap` | `0.5em` | The progress bar floats this far inside the card. `0` puts it at the bottom edge |
| `--jt-badge-corner` | `1` | Watched and count badges sit in the corner of cards. `0` gives Jellyfin's round badges |
| `--jt-cast-round` | `1` | Round photos for cast and crew. `0` gives Jellyfin's tall photos |
| `--jt-episode-tiles` | `1` | Episodes of a season as tiles (desktop). `0` gives Jellyfin's list |
| `--jt-compact-lists` | `1` | "Upcoming on TV" and similar lists on item pages as compact tiles. `0` gives one row per entry |
| `--jt-backdrop-height` | `58vh` | Height of the backdrop picture on item pages in wide windows. Jellyfin's own: `40vh` |
| `--jt-card-extra-buttons` | `flex` | Watched and favourite buttons on hovered cards. `none` hides them |
| `--jt-card-mini-buttons` | `flex` | Small play button on cards on phones. `none` hides it |
| `--jt-library-labels` | `block` | Names under the library cards on the home page. `none` hides them |
| `--jt-library-style` | `0` | `1` shows the library cards on the home page as the theme's banner with the name in the middle in the theme's style, instead of Jellyfin's pictures with the name in plain white |
| `--jt-original-title` | `block` | Original title on item pages. `none` hides it |
| `--jt-detail-logo` | `block` | Logo on item pages. `none` hides it |
| `--jt-item-title` | `block` | Title on item pages. `none` hides it |
| `--jt-footer` | `block` | Theme name, version and author. `none` hides it |
| `--jt-mascot-login` | `1` | The jellyfish above the login card. `0` hides it |
| `--jt-mascot-footer` | `1` | The small jellyfish in the footer. `0` hides it |
| `--jt-mascot-empty` | `1` | The jellyfish on empty pages ("Nothing here"). `0` hides it |
| `--jt-mascot-menu` | `1` | The jellyfish at the end of the menu drawer. `0` hides it |
| `--jt-mascot-bg` | `1` | A large, faint jellyfish in the background of every page. `0` hides it |

While a page loads, a floating jellyfish replaces Jellyfin's spinning circle.
| `--jt-footer-fixed` | `1` | The footer as a slim bar at the bottom of the screen on every page. `0` puts it at the end of each page instead. On TVs and phones it is at the end of each page by default; `1` puts the bar there too |
| `--jt-login-text` | `""` | A heading on the login page, e.g. `"Welcome home"` |
| `--jt-login-bg` | `none` | Background picture of the login page, e.g. `url("https://...")` |
| `--jt-logo` | JellyThemes logo | Logo in the top bar and on the login page. Your own: `url("https://...")`, Jellyfin's: `normal`. See [Own logo](#own-logo) |
| `--jt-logo-height` | `1.6em` | Height of your logo in the Jellyfin 12 top bar, e.g. `2em` for a logo with text |
| `--jt-logo-banner` | `0` | `contain` shows Jellyfin's banner behind the logo in the classic layouts |
| `--jt-server-name` | `0` | `1` shows the server name next to the logo in the Jellyfin 12 top bar |

### Own logo

Put your logo somewhere online (as a PNG or SVG with a transparent background) and add:

```css
:root {
    --jt-logo: url("https://example.com/my-logo.png");
    --jt-logo-banner: 0;
}
```

Jellyfin's own logo back: `--jt-logo: normal; --jt-logo-banner: contain; --jt-server-name: 1;`

Make your logo bigger or smaller with `--jt-logo-height`. With `--jt-server-name: 1` the Jellyfin 12 top bar also shows your server name next to the logo; you can change it under **Dashboard > General**.

### Own colors

Start from the theme closest to your colors and set your own under it. Every color is written three times: as hex, as `r, g, b` with commas and as `r g b` with spaces (older TVs need the comma version, Jellyfin 12 the space version). This example makes Solaris rose red:

```css
:root {
    /* accent, a lighter one, and the lightest one */
    --jt-accent: #e11d48;   --jt-accent-rgb: 225, 29, 72;    --jt-accent-ch: 225 29 72;
    --jt-accent-2: #f43f5e; --jt-accent-2-rgb: 244, 63, 94;  --jt-accent-2-ch: 244 63 94;
    --jt-accent-3: #fb7185; --jt-accent-3-rgb: 251, 113, 133; --jt-accent-3-ch: 251 113 133;
    /* text on accent buttons, section titles */
    --jt-on-accent: #ffffff; --jt-on-accent-rgb: 255, 255, 255; --jt-on-accent-ch: 255 255 255;
    --jt-title: #f43f5e;     --jt-title-rgb: 244, 63, 94;       --jt-title-ch: 244 63 94;
}
```

The backgrounds work the same way, from darkest to lightest: `--jt-bg-1`, `--jt-bg-2` and `--jt-bg-3`, each with `-rgb` and `-ch`.

### Faster on older TVs

All effects are on by default, also on TVs (Jellyfin's TV display mode). If a TV feels slow (older Samsung and LG models), turn blur, glow and animations off there. This only changes the TV display mode:

```css
:root {
    --jt-tv-blur: none;
    --jt-tv-glow: 0 0 0 3px var(--jt-accent);
    --jt-tv-glow-s: none;
    --jt-tv-motion: 0s;
}
```

In the TV display mode the top bar stays at the top while you scroll (Jellyfin lets it scroll away there). It is opaque and has no blur, so it costs a TV nothing while scrolling.

### Inter font

The themes use Jellyfin's own font, so nothing extra has to load. For the Inter font, add this line **above** the theme's `@import` line:

```css
@import url("https://cdn.jsdelivr.net/npm/@fontsource-variable/inter@5.1.0/index.css");
```

## Compatibility

### Jellyfin
- Jellyfin 12 (tested on 12.4) in every display mode: Auto, Desktop, Mobile and TV. Jellyfin 12 does not load Custom CSS in the dashboard, so the dashboard keeps Jellyfin's own look there
- Jellyfin 10.11
- Jellyfin 10.10

### Apps
Custom CSS only works in apps that show the Jellyfin web interface:

- Jellyfin Web in any modern browser (Chrome, Firefox, Safari, Edge)
- Jellyfin Media Player / Jellyfin Desktop
- Jellyfin for Android (phones and tablets)
- Jellyfin for iOS
- Jellyfin for LG webOS and Samsung Tizen TVs

Native apps draw their own interface and ignore Custom CSS, so the themes do not show up there. This includes Swiftfin, Jellyfin for Android TV / Fire TV, Findroid and Kodi.
